# Паспорт объекта — извлечение из Word

## Установка

    pip install -r requirements-dev.txt

Эта команда уже ставит всё нужное для резервного распознавания полей с
картинок (`easyocr`) — отдельных программ или прав администратора не
требуется.

## Запуск

    python run.py

Откройте http://127.0.0.1:5000 в браузере.

### Резервное распознавание полей с картинок (OCR)

По умолчанию **выключено**: на обычном процессоре (без видеокарты)
распознавание одной картинки может занимать несколько минут, и на время
загрузки страница проекта не открывается. Без OCR поля, которых нет в
обычном тексте документа, остаются пустыми — их можно заполнить вручную.

Чтобы включить OCR для конкретного запуска, задайте переменную окружения
перед стартом:

    # PowerShell
    $env:OCR_FALLBACK_ENABLED="1"; python run.py

    # cmd
    set OCR_FALLBACK_ENABLED=1 && python run.py

При первом использовании с включённым OCR один раз скачиваются файлы
модели распознавания — на это нужен интернет разово, дальше не требуется.
Если скачать не удалось — приложение продолжает работать как обычно,
резервное распознавание просто ничего не находит, поля с картинок
остаются пустыми.

## Выгрузка сравнения в Excel

Отметьте нужные проекты галочками в списке и нажмите «Выгрузить в Excel» —
скачается файл в том виде, в каком сравнение стоимости обычно ведут на бумаге:
один лист, проекты идут колонками. У каждого проекта сверху название, под ним
фото объекта, дальше год подписания, класс, генподрядчик, площади и ставка НДС,
а ниже — таблица стоимости по видам работ.

Та же кнопка есть и на самой странице сравнения, рядом с «Сохранить в PDF».

Файл рассчитан на то, чтобы с ним работали дальше:

- Стоимость по видам работ остаётся пустой — её заполняют из сметы вручную.
  Пока она пуста, итоговая строка показывает цену работ по договору.
- Все ₽/м² и итоги пересчитываются сами: впишите суммы или поправьте общую
  площадь — колонка пересчитается.
- Рядом с ценой за м² каждого проекта красным показано, насколько он дороже или
  дешевле первого выбранного.
- Жёлтым подсвечено то, что программа не смогла найти в документах, — эти
  ячейки нужно заполнить самому. Нулями они не заполняются, чтобы пустое
  значение нельзя было принять за настоящий ноль.

Ставка НДС ставится по году подписания договора: 20% по 2025 год включительно,
22% начиная с 2026-го.

## Тесты

    pytest

Тесты, использующие реальные примеры документов (папка `tests/fixtures/`),
пропускаются, если файлы туда не скопированы. Тест на реальное
распознавание текста (`tests/test_ocr.py`) пропускается, если EasyOCR не
смог инициализироваться (например, нет сети для первой загрузки модели).
Чтобы прогнать всё:

1. Скопируйте `250204 ДГП_Пр_Мира.docx` → `tests/fixtures/dgp_mira.docx`
2. Скопируйте `Прил. 1. Техническое задание Проспект Мира.docx` →
   `tests/fixtures/tz_mira.docx`
3. Убедитесь, что зависимости установлены (см. "Установка")
4. Запустите `pytest -v`

## Ручная сквозная проверка

1. `python run.py`
2. Откройте http://127.0.0.1:5000, нажмите "Создать проект"
3. Введите название "Проспект Мира", загрузите те же 2 файла из шага выше
4. После создания должна открыться страница проекта: Генподрядчик = "ООО «АНТТЕК»"
   заполнен автоматически (зелёный значок)
5. Без `OCR_FALLBACK_ENABLED=1` поля площади (подземная/надземная/общая)
   останутся пустыми — это ожидаемо, впишите значения вручную. Если запустили
   с включённым OCR — эти поля должны заполниться значениями, распознанными
   с картинки на листе 5 ТЗ (67 413 / 13 297 / 54 116 м², порядок полей может
   отличаться), с синим значком "С картинки — проверьте", но на обычном
   процессоре это может занять несколько минут.
6. Год подписания и класс здания — пустые, подсвечены жёлтым, доступны для
   ручного ввода
7. Впишите значения в пустые поля, нажмите "Сохранить" — после перезагрузки
   страницы введённые значения должны сохраниться, а с полей, заполненных
   через OCR, значок "проверьте" должен исчезнуть, если вы изменили значение
